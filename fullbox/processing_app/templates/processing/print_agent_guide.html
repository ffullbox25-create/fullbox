Fullbox Agent

1

Подготовьте рабочее место

Подключите TSC TE200, проверьте бумагу и выполните обычную тестовую печать из Windows. В очереди Windows не должно быть зависших заданий.

2

Скачайте и установите агент

Нажмите «Скачать установщик», откройте файл и подтвердите запрос Windows UAC. Установщик сам остановит предыдущий Fullbox Agent, обновит файлы и добавит запуск вместе с Windows.

Это пилотная неподписанная сборка. Скачивайте её только с этой страницы. Если Windows показывает SmartScreen, сначала сверьте SHA-256 ниже, затем выберите «Подробнее» → «Выполнить в любом случае».
3

Привяжите этот компьютер

На этой странице нажмите «Создать код», затем скачайте мастер привязки. Распакуйте архив, запустите Run-Fullbox-Agent-Register.cmd и введите код. Мастер проверит отдельно сканирование и печать, сохранит индивидуальный токен и перезапустит агент.

Код одноразовый и действует 10 минут. Запускайте привязку только на том компьютере, для которого создан код.
4

Назначьте принтер

Откройте «Принтеры и сканеры», выберите появившийся агент этого ПК и точное имя TSC TE200. Для первого теста назначьте только реально установленный формат этикетки.

5

Выполните контрольную печать

Сначала распечатайте одну тестовую этикетку из настроек. Затем создайте одно небольшое задание обработки и проверьте одну этикетку короба. Не запускайте массовую печать до успешного результата.

6

Зафиксируйте результат

Проверьте размер, ориентацию, читаемость QR/штрихкода и отсутствие дублей. Статус «передано в очередь Windows» ещё не означает, что бумага физически вышла из принтера.

Что считать успешным тестом

  • значок Fullbox Agent появился возле часов;
  • агент виден онлайн в настройках;
  • TSC TE200 найден по точному имени Windows;
  • вышла ровно одна этикетка без дубля;
  • QR/штрихкод считывается сканером;
  • после перезапуска ПК агент подключился сам.
Если привязка или печать завершилась ошибкой: остановите дальнейший тест, не удаляйте резервную копию config.json и сохраните скрин ошибки, время теста и имя компьютера.
